# モデルと実装

各人は無知 I，拡散者 S，抑制者 R のいずれかです．各拡散者は率 1 で会話を始めます．一様に選んだ接触相手が I なら確率 `lambda` で S になり，相手が S または R なら確率 `sigma` で話し手だけが R になります．忘却は対象者 1 人あたり率 `delta` で起こり，その人を I に戻します．既定の対象は S と R で，`stifler_only` では R だけです．

Rust 実装は，socsim エンジンの長さ 1 のステップ内で連続時間 Gillespie 事象を処理します．ステップ境界を越えた事象は次のステップへ保持します．ER ネットワークは `socsim-net` で生成して一度だけ CSR 配列へ移し，事象ループでは `Network::neighbors()` を呼びません．

ネットワークと力学の乱数系列は別々に導出します．同じ試行 seed の ER ネットワークは全パラメータ条件で共有します．Rayon の並列度は試行の出力順と乱数系列を変えません．

シミュレーションは，試行要約，条件集計，選択した時系列を 1 つの runvault run に記録します．準定常値は，時刻 `[T/2, T]` の整数時刻標本を，時刻 T で拡散者が残る試行だけで平均した値です．
